Plataforma propia para gestión de pistas de pádel en comunidades residenciales. Empezó en web y crece hacia móvil con Kotlin Multiplatform. Producto real donde tomo todas las decisiones: arquitectura, diseño y negocio. Validada en producción durante el torneo **II Premier Pádel Villajardín**.
